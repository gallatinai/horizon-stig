# MPN requirements

Gallatin deploys and manages Horizon on UDS Core for MPN. Defense Unicorns supplies UDS Core software; DU's managed IL5/IL6 clusters are a separate deployment. UDS settings are established from the pinned Core source and Gallatin's configuration.

The package baseline uses shared UDS identity as specified by its [release contract](evidence/delivered-release/platform-contract.json). MPN-specific host, storage, certificates and network settings belong in Gallatin's deployment configuration. The separate DU-managed deployment does not supply MPN's operating configuration or authorization.
